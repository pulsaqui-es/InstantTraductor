# InstantTraductor

Traductor simultáneo para Windows: lo que suena en los auriculares del PC se oye, casi en tiempo real, hablado en español.

- Idioma de origen principal: inglés. Después, japonés y chino.
- Funciona 100 % en local (GPU NVIDIA), sin servicios de pago.

**Estado:** en diseño. El proyecto sigue un desarrollo guiado por especificaciones (SDD).
